# Агент для записи и конспектирования пар

Агент знает твоё расписание, записывает пару с микрофона или со звука конкретной вкладки браузера, расшифровывает речь прямо на твоём компьютере через Whisper и делает из расшифровки конспект с помощью Claude: разделы с метками времени, определения, формулы в LaTeX, домашка и дедлайны, вопросы для самопроверки. Предмет, вид занятия и его номер подставляются из расписания сами.

## Установка

Нужен Python 3.9 или новее. В папке с агентом выполни:

```
pip install -r requirements.txt
```

На Linux дополнительно понадобится PortAudio (`sudo apt install libportaudio2`), на Windows и macOS больше ничего ставить не нужно. При первой расшифровке Whisper скачает модель (для `small` это около 500 МБ), после этого расшифровка работает без интернета. Эта первая загрузка идёт несколько минут, и на странице всё это время висит «расшифровка 0%»: так и должно быть, ход загрузки виден только в `.launcher/agent.log`.

## Ключ API

Запись и расшифровка работают без всякого ключа и без интернета. Ключ нужен только на последнем шаге, где из расшифровки делается конспект. Подойдёт любой из четырёх вариантов.

**OpenRouter, бесплатно.** Один ключ к десяткам моделей, среди них есть с нулевой ценой и контекстом на миллион токенов. Регистрация на openrouter.ai через Google или GitHub, ключ создаётся в разделе Keys. Работает там, где API Google и Groq уже недоступны.

```
setx OPENROUTER_API_KEY "sk-or-..."
```

Пока в `config.yaml` стоит `openrouter_free_only: true`, агент перед каждым запросом сверяется с прайс-листом OpenRouter и отказывается работать с платной моделью. Так опечатка в названии не превратится в счёт.

**Claude Code, без ключа.** Если на компьютере стоит Claude Code, агент может звать его напрямую: конспект оплачивает подписка, ключ не нужен. Один раз выполни `claude login` в терминале и поставь в `config.yaml` строку `provider: claude_cli`.

**Gemini, бесплатно.** Ключ создаётся на aistudio.google.com («Get API key»). Важно: Gemini API обслуживает не все страны, из закрытого региона он отвечает `User location is not supported` при полностью рабочем ключе.

```
setx GEMINI_API_KEY "AIza..."
```

**Claude API, платно.** Ключ из консоли platform.claude.com, раздел API Keys. Конспекты заметно лучше, одна полуторачасовая пара обходится примерно в 10-20 центов.

```
setx ANTHROPIC_API_KEY "sk-ant-..."
```

На macOS или Linux вместо `setx` (для bash замени `~/.zshrc` на `~/.bashrc`):

```
echo 'export OPENROUTER_API_KEY="sk-or-..."' >> ~/.zshrc
source ~/.zshrc
```

Переменная видна только заново запущенным программам, так что терминал после `setx` нужно перезапустить, а если агент открывается ярлыком, то перезайти в систему.

Кто именно пишет конспект, задаётся в `config.yaml` полем `summary.provider`. При `auto` берётся первый, для кого есть ключ, в порядке Claude, OpenRouter, Gemini, а если ключей нет вовсе, то установленный `claude` CLI. Значения `openrouter`, `claude_cli`, `gemini` и `anthropic` выбирают явно, модели задаются там же соседними полями.

Совсем без ключей агент всё равно запишет и расшифрует пару, а рядом положит файл `prompt_for_claude.md`: его можно загрузить в обычный чат с любой моделью и получить такой же конспект руками.

## Ярлык на рабочем столе

Это только для Windows: ярлык опирается на `pythonw.exe` и `.lnk`. На macOS и Linux агент запускается командой `python agent.py ui` из раздела ниже.

Один раз сделай ярлык, дальше терминал не понадобится:

```
python make_shortcut.py
```

На рабочем столе появится «Агент пар». Двойной клик по нему поднимает агента и открывает страницу, никакого чёрного окна при этом не возникает. Второй клик по тому же ярлыку не запускает второго агента, а спрашивает, открыть страницу или остановить работающего. Остановка мягкая: агент дописывает начатую запись и доделывает расшифровку, которая уже в очереди.

Если что-то пошло не так, ярлык покажет окно с ошибкой, а подробности останутся в `.launcher/agent.log`. Туда же попадает всё, что агент обычно печатает в терминал. Убрать ярлык: `python make_shortcut.py --remove`.

Ключ `ANTHROPIC_API_KEY` ярлык видит не сразу: `setx` доходит только до заново запущенных программ, поэтому после установки ключа нужно перезайти в систему, а не просто перезапустить терминал.

## Приложение

Открывается ярлыком, а из терминала так:

```
python agent.py ui
```

Страница живёт на `127.0.0.1:8756`, и всё остальное делается на ней.

На вкладке «Расписание» день показан осью времени: слева часы, справа пары. Точка у текущей пары горит красным, прошедшие приглушены, а зелёные точки под числами недели показывают, какие пары уже записаны. Стрелками листаются недели.

Внизу закреплена панель записи. Она сама знает, что идёт сейчас, поэтому кнопка «Записать пару» сразу пишет нужный предмет: во время записи там таймер и индикатор громкости, а после остановки видно, как идёт расшифровка и написание конспекта.

На вкладке «Конспекты» лежат все записи. Конспект открывается прямо на странице, метки времени подсвечены, рядом переключатель на полную расшифровку и проигрыватель записи, чтобы переслушать спорное место.

Страницу можно открыть и с телефона, если он в той же сети: замени в адресе `127.0.0.1` на адрес компьютера. По умолчанию сервер слушает только сам компьютер, так что для этого в `agent.py` нужно поменять адрес в `ThreadingHTTPServer` на `0.0.0.0`, и делать это стоит только в домашней сети.

## Расписание

Расписание лежит в `schedule.yaml`: группа, подгруппа, время московское. Агент сам берёт нужную подгруппу по полю `subgroup` в начале файла. Очные пары помечены `remote: false`, остальные дистанционные.

В репозитории этого файла нет: в нём ссылки на занятия, а у некоторых пароль прямо в адресе, поэтому `schedule.yaml` лежит в `.gitignore` и остаётся только на компьютере. Рядом есть `schedule.example.yaml` с разобранным по комментариям форматом: скопируй его в `schedule.yaml` и впиши свои пары. Если запустить агента ярлыком, не сделав этого, он предложит скопировать пример сам. По той же причине в репозиторий не попадает папка `lectures/`: записи, расшифровки и конспекты никуда с компьютера не уезжают.

Если привычнее терминал, всё то же есть командами:

```
python agent.py timetable              пары на сегодня и ближайшая
python agent.py timetable -w           вся текущая неделя
python agent.py timetable -d 2026-11-05  конкретный день
python agent.py timetable -s робото    все занятия по предмету и сколько осталось
```

Даты в расписании записываются так же, как в справке вуза: `14.09-19.10 к.н.` это каждую неделю, `27.10-24.11 ч.н.` через неделю, можно перечислить конкретные даты через запятую. При запуске агент проверяет, что даты совпадают с днями недели, и ругается, если в расписание закралась опечатка.

## Как называются записи

Номер занятия агент считает сам: он знает все даты каждого предмета, поэтому пара 7 октября это «Семинар 4 из 4» по базам данных. Папка получает имя по дате и номеру, а конспект получает шапку с преподавателем и видом занятия:

```
lectures/
  Базы, банки и анализ данных/
    2026-09-16 Семинар 01/
    2026-10-07 Семинар 04/
      notes.md
```

Поэтому предмет вводить не нужно: команды `record` и `process` без `-s` сами смотрят в расписание по времени записи, а расширение для браузера подставляет название текущей пары. Если записываешь что-то вне расписания, задай название через `-s`.

## Как пользоваться

Сначала посмотри, какие микрофоны видит агент, и сделай пробную запись на 30 секунд:

```
python agent.py devices
python agent.py record -s "Матанализ" -m 0.5
```

Во время записи видна строка с таймером и индикатором громкости. Если полоска не шевелится, когда кто-то говорит, агент слушает не тот микрофон: возьми номер нужного из `devices` и впиши его в `config.yaml` в поле `audio.device`.

Обычная запись идёт до Ctrl+C, после чего сразу начинаются расшифровка и конспект. Предмет подставится из расписания:

```
python agent.py record
```

Если пару записал телефон, перекинь файл на компьютер и обработай его (подходят m4a, mp3, wav, ogg, webm и другие форматы):

```
python agent.py process lecture.m4a -s "История"
```

## Запись вкладки браузера

Если пара идёт онлайн (Zoom, Teams, Вебинар, запись на YouTube), писать её микрофоном бессмысленно. В папке `extension` лежит расширение для Chrome, Edge или другого браузера на Chromium: оно забирает звук прямо из выбранной вкладки. Дальше можно переключаться на другие вкладки, сворачивать браузер и работать в других программах, а писаться будет именно та вкладка, которую ты выбрал, и только она. Звук с твоего микрофона в запись не попадает, а лекцию по-прежнему слышно.

Установка (один раз):

1. Открой `chrome://extensions`, включи «Режим разработчика» в правом верхнем углу.
2. Нажми «Загрузить распакованное расширение» и выбери папку `extension`.
3. Закрепи появившуюся иконку на панели, чтобы она была под рукой.

Как записывать:

1. Запусти агента ярлыком «Агент пар» (или командой `python agent.py serve`, если страница не нужна).
2. Открой вкладку с лекцией и нажми иконку расширения. Оно спросит у агента, что идёт по расписанию, и само покажет предмет, номер занятия и время окончания. Остаётся нажать «Начать запись».
3. Занимайся своими делами. Когда пара кончится, нажми иконку ещё раз и останови запись.

Дальше агент сам расшифрует пару и положит конспект в `lectures`, как и при обычной записи. Пока идёт запись, на иконке горит красный значок REC, а звук уходит агенту небольшими кусками, поэтому даже если браузер закроется посреди пары, записанное останется на диске.

Если агент не запущен или его закрыли, расширение ничего не теряет: оно сохранит запись файлом в Загрузки, а ты потом обработаешь её командой `python agent.py process`. Если случайно закрыть вкладку с лекцией, запись тоже корректно завершится и сохранится.

Firefox так не умеет: захват отдельной вкладки есть только в браузерах на Chromium.

## Автоматическая запись по расписанию

```
python agent.py schedule
```

В этом режиме агент сам включает микрофон на очные пары, пишет их целиком с небольшим запасом до и после и отправляет на расшифровку в фоне, так что следующая пара запишется, даже если предыдущая ещё обрабатывается. Про дистанционные пары он пишет напоминание в консоль: их звук берётся из вкладки, а её нужно выбрать руками.

Ярлыка для этого режима нет: у него нет своей страницы, и в фоне без окна он работал бы вслепую. Поэтому `schedule` запускается из терминала и остаётся открытым, а ярлык в это время держит приём записей из вкладок. Если очные пары устраивает записывать руками, то `schedule` не нужен вовсе: кнопка «Записать пару» на странице делает то же самое.

Ноутбук при этом должен быть включён и не уходить в сон. Если носишь его с закрытой крышкой, отключи в настройках питания сон при закрытии крышки.

## Что получается

```
lectures/
  Математический анализ/
    2026-09-14_09-00/
      audio.flac         запись (audio.webm, если писалась вкладка браузера)
      transcript.txt     расшифровка с метками времени
      notes.md           конспект
```

Конспекты в Markdown с формулами LaTeX удобно открывать в Obsidian, Typora или VS Code. Метки времени в заголовках помогают быстро найти нужное место в записи.

## Как улучшить качество

Больше всего на результат влияет расстояние до преподавателя. Ноутбук на задней парте пишет в основном шум аудитории, а телефон на первой парте или недорогой петличный микрофон дают гораздо лучшую запись, которую потом можно обработать командой `process`.

Если в расшифровке много ошибок, поставь в `config.yaml` модель `medium` или `large-v3-turbo`: они медленнее, но заметно точнее. С видеокартой NVIDIA (`device: cuda`) расшифровка ускоряется в разы.

Свои пожелания к формату конспекта можно дописать в `summary.extra_instructions`, например попросить писать короче или добавлять примеры кода.

И не забудь спросить у преподавателя, можно ли записывать пару.
